# Category A — I2C FPGA / RTL Controllers

This document contains literature related to FPGA and RTL implementation
of I2C controllers.

## Questions

For each paper:

1. What architecture is used?
2. What I2C features are implemented?
3. Is the implementation master, slave, or both?
4. What FPGA/device is used?
5. What resources are reported?
6. What timing/performance is reported?
7. Does it implement clock stretching?
8. Does it implement arbitration?
9. Does it implement fault handling?
10. What limitations remain?
